ПРОЕКТ: School Schedule Widget (класс 9Б)
Платформа: Android (Xiaomi), KWGT. Репозиторий: https://github.com/Bobrikha/school-shedule (публичный)

ЦЕЛЬ
Виджет показывает следующий урок 9Б: предмет, кабинет, время начала и конца, "через N мин".
Данные берутся из листов "Изменение на ДД.ММ.ГГ" на sch78kras.ru. Работает офлайн по последним
сохранённым данным. Нужны состояния: уроки закончились, выходной, нет данных.

ИСТОЧНИК ДАННЫХ
- sch78kras.ru на WordPress. Расписание на день публикуют записью "Изменение на 22.10.26".
  В записи около 12 картинок PNG, текста нет.
- Дата публикации записи может быть раньше даты расписания (запись от 21.10 на 22.10).
  В заголовках бывают приписки ("на 16.10.26 г.").
- 9Б находится в картинке с таблицей: колонки 8Ж, 9А, 9Б, 9В, 9Г.
- Постоянное расписание 9Б на сайте не найдено (в меню видны только 1-4 классы),
  поэтому работаем только по листам изменений.
- Звонки (страница "Расписание звонков"), уроки 1-12:
  08:30-09:10, 09:20-10:00, 10:15-10:55, 11:05-11:45, 11:55-12:35, 12:45-13:25,
  13:40-14:20, 14:30-15:10, 15:15-15:55, 16:00-16:40, 16:45-17:25, 17:30-18:10.
  По понедельникам есть нулевой урок 08:00-08:30, на листах 9Б он не встречался.

ЧТО СДЕЛАНО
1. fetch_schedule.py
   - берёт записи через /wp-json/wp/v2/posts;
   - скачивает картинки в полном размере (убирает суффикс -1024x705);
   - находит сетку таблицы (OpenCV), колонку "9 Б" (OCR шапки, регулярка ^9\s*[Бб6]$),
     читает предмет (Tesseract rus) и кабинет (eng, только цифры и дефис);
   - пишет schedule.json.
2. .github/workflows/schedule.yml
   - запуск раз в 30 минут и вручную (workflow_dispatch);
   - ставит tesseract-ocr-rus, обновляет schedule.json;
   - запуск занимает 7-10 минут;
   - добавлены concurrency и git pull --rebase -X theirs.
3. schedule.json
   - поля: class, updated, bells, days, seen;
   - days: ключ YYYY-MM-DD, внутри source, lessons[{n, subject, room, start, end}];
   - в новой версии скрипта добавлено: byn (урок по номеру, с sm/em в минутах),
     nx[0..13] (ближайший урок с номером >= k, 99 = нет), last.

ЧТО ПРОВЕРЕНО
- Скрипт находит 9Б, названия предметов и кабинеты читаются правильно.
- KWGT читает файл по raw-ссылке. Работают:
  $wg("<url>", json, ".class")$
  $wg("<url>", json, ".days['2026-10-16'].lessons[0].subject")$  (и .room)
  Путь в JSON должен начинаться с точки.
